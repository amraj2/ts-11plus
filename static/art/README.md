# Runner artwork

`runner-pixel-sheet.png` is Pip's original artwork, preserved unchanged. Four columns by two rows: run 1–4, idle, think, stumble, celebrate. The renderer uses nearest-neighbour scaling and preserves source alpha without palette swaps.

The other 49 characters have individual transparent animation sheets in `characters/<id>.png`, generated with the built-in image-generation tool. Each follows the same eight-frame layout. The lobby grid displays the idle frame; the lobby preview and races use the matching character's animation. The server supplies content-versioned URLs and includes every sheet in offline caching.

`characters/generation.json` records the prompt template and all names/themes. Replace `CHARACTER` in `basePrompt` with `<name>, <theme>` to recover each prompt; Nova uses the recorded `novaPrompt` override.
